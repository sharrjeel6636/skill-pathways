# RELEASE_QA.md - RC 1.0.0

## 1. Student Journey
- [x] Register: Account created, navigated to onboarding.
- [x] Quiz: Questions load, progress bar updates, submits correctly to /quiz/result.
- [x] Roadmap: Viewable, progress states (done/locked) accurate.
- [x] Course: Detail view functional, real URL opens.
- [x] Career: Explorer filter functional.
- [x] Chatbot: Replies context-aware, no stack traces.
- [x] Logout: Redirected to landing.

## 2. Parent Journey
- [x] Register: Account created, dashboard prompts for link.
- [x] Redeem Link: Code generated by student and redeemed by parent links account.
- [x] Dashboard: Linked child's real progress data displayed.
- [x] Chatbot (Parent Mode): Context reflects child name/field.

## 3. Bad-Case Scenarios
- [x] Wrong password: Handled, clear error message.
- [x] Airplane mode: AsyncStateView displays retry UI.
- [x] Expired session: Redirected to login.
- [x] Invalid parent link code: Handled, "Invalid code" message.

## 4. Known Limitations
- **Seed Data:** University/scholarship data is limited/representative, not comprehensive for all Pakistan regions.
- **Web App:** MVP scope only (landing, auth, dashboard, quiz, roadmap, chatbot).
- **Offline-first:** App expects network connectivity for data; minimal local caching.
- **Analytics:** Counselor analytics dashboard is out-of-scope for this release.
