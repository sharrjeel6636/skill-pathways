# Contributing to Skill Pathway

Thank you for your interest in contributing to Skill Pathway!

## Branch Naming Convention
Please use the following format for branches:
- `feature/<short-description>`
- `fix/<issue-number>`

## Verification Requirement
Every PR must include evidence that the work is complete. Checklists are not enough. Please include:
- `flutter analyze` output showing zero errors.
- Verification evidence (e.g., screenshots of UI, curl/Postman output for API changes) in the PR description.

## Running Tests
Before submitting a PR, ensure all local tests pass (to be added in Phase 3).
